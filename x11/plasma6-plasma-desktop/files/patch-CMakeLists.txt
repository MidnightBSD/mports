SCIM is located with pkg_check_modules, which CMAKE_DISABLE_FIND_PACKAGE_SCIM
does not affect, so the port's SCIM option could never turn the backend off and
an installed textproc/scim was always compiled in. The kimpanel SCIM backend
does not build against libc++ (scim's ucs4_t is unsigned int and there is no
std::char_traits for it), so the port failed whenever scim was installed.

Honour CMAKE_DISABLE_FIND_PACKAGE_SCIM around the lookup.
